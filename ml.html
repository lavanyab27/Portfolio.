01 · Problem Statement

Why this project?

I place orders on Blinkit at different times of the day — often twice or more. I realized my orders have patterns I'm not even conscious of. This project makes those patterns visible and learnable for a machine.

Swipe to explore objectives →
🎯

The Question

Given what time it is, what day it is, how much I spent, and what I ordered previously — can a model predict my next order category?

🧠

Why Classification?

The target — order category — is a discrete label (Fruits, Snacks, Dairy…). This is a multi-class classification problem, not regression.

📊

The Output

A trained model that takes 7 input features and outputs a predicted category — with accuracy score, confusion matrix, and feature importance.

04 · Model Building

Training the classifier

I tested both a Decision Tree and a Random Forest. The Random Forest performed better (82% vs 74%), so that became the final model.

blinkit_predictor.py
# ── Load & prepare data ────────────────
import pandas as pd
from sklearn.preprocessing import LabelEncoder

df = pd.read_csv('my_blinkit_orders.csv')
le = LabelEncoder()

for col in ['day_of_week', 'hour_of_day',
           'previous_category', 'next_category']:
    df[col] = le.fit_transform(df[col])

# ── Feature / label split ──────────────
X = df[['day_of_week', 'hour_of_day',
        'total_amount', 'basket_size',
        'previous_category']]
y = df['next_category']

# ── Train / test split ─────────────────
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y,
    random_state=42)

# ── Train Random Forest ────────────────
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(
    n_estimators=100, random_state=42)
rf.fit(X_train, y_train)

# ── Evaluate ───────────────────────────
from sklearn.metrics import (accuracy_score,
    classification_report, confusion_matrix)

y_pred = rf.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.2%}")
print(classification_report(y_test, y_pred))

Why stratify=y? Snacks and Fruits dominate my dataset. Without stratification the test set might accidentally contain mostly those — giving misleadingly high accuracy. Stratified split ensures all 6 categories are proportionally represented.

06 · Behavioral Insights

What the model learned about me

Beyond accuracy scores, the most valuable output is what the feature importance and EDA revealed about my actual habits.

Swipe to explore insights →
🌙
"Most night orders are Snacks"21 of 24 night-slot orders (87%) were snack-category. The model learned this so strongly that Snacks had 100% test precision.
🍎
"Most morning orders are Fruits"16 of 24 morning orders were Fruits or Dairy — the most health-conscious ordering window in my data.
📅
"Sunday is my highest-order day"20 orders in 6 weeks, mostly evening and night. Groceries and Snacks dominate Sunday orders specifically.
🔁
"Previous category is the best predictor"With importance score 0.34, what I ordered last is the strongest signal for what I'll order next. Snacks tend to follow Snacks.
What I'd do next
01Collect more data — 78 rows is functional but more orders would improve minority class prediction (Beverages, Personal Care)
02Add a "days since last order" feature — ordering frequency might signal urgency and category
03Try XGBoost for potential accuracy improvement on the small dataset
04Build a simple input form that takes time + previous category and outputs a live prediction
